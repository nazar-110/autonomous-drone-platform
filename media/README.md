# Media

Add project media here as the platform develops.

Recommended files:

- `manual-flight-test.mp4` or a link to the flight video
- assembled drone photos
- electronics layout photos
- future custom-frame CAD renders
- ROS 2 / RViz screenshots
- future SLAM visualization

For a public GitHub repository, short compressed videos or externally hosted video links are often easier to view than very large raw video files.
